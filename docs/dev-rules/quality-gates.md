# 验证与交付门禁

只声明实际执行结果。文档、Rust 工程和现有 Python 回归命令已存在；不能用文档门禁替代产品测试。阶段编排脚本的实际覆盖/待建入口见当前计划，不把旧阶段父提交约束当成本轮结论。

## 当前可运行

在仓库根执行 `python scripts/check_docs.py` 和 `git diff --check`。Python 3.12+、标准库，无第三方包。

检查自有 Markdown 的登记/元数据、相对文件链接和本仓约定的标题/显式锚点、重复 FR/NFR/AC 定义、需求追踪完整性与合法引用、有效阶段/状态、追踪设计路径。忽略 Git、依赖、构建和本地数据目录。采用受限 Markdown 语法检查，不宣称完整 CommonMark 解析或外部 URL 在线有效。

登记表的 currentStage/retireAfter 检查防止跨阶段遗留过程文档；本机绝对路径检查也覆盖代码围栏。负向回归在 `tests/python/test_doc_governance.py`，只修改临时副本。

文档统一使用内联相对链接；校验器拒绝未支持的参考式链接以避免漏检。`CLAUDE.md` 的 `@AGENTS.md` 单独校验。非 Markdown 目标检查存在性；运行事实、语义冲突、授权和开源许可仍需审核。

R1 清单存在后同时检查必要用例字段、ID、工作包引用及全部 P0/NFR 覆盖；只证明定义没有遗漏，不会把用例自动标为已运行。

`.github/workflows/docs.yml` 使用同一入口；文件存在不表示远端 CI 已运行或分支保护已配置。校验器变更需用临时目录验证坏链接、漏登记、错误追踪等会返回非零，不在正式文档植入永久测试错误。

## 已有产品工程的适用检查

| 变更 | 要求与证据 |
| --- | --- |
| Rust 核心/接口 | `cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --workspace --locked`；金额/数量/修订与失败样本 |
| Rust 模型客户端/编排 | 两协议真实客户端连接受控端点；SSE/工具配对/部分流不重放/取消/压缩/持久恢复；纳入 Cargo 与 R1 检查 |
| 数据库/迁移 | 幂等、故障注入、旧库升级、一致性备份与新目录恢复、引用和哈希校验 |
| 金融规则 | AC 手算期望、Decimal 精度/溢出、守恒性质；不能用被测实现生成全部期望 |
| UI/图表 | 真实启动与关键路径，中文输入/缩放/键盘，当前数据量性能；低影响样式不强制镜像单测 |
| 外部模型/行情 | 受控端点故障测试默认无凭据；真实能力/权限验证另记结果和数据范围 |
| 分发 | Windows 干净环境、离线依赖、备份恢复、锁版本与传递许可清单 |

相关检查通过后不无理由扩大重跑；公共契约、金融/存储与工具边界变化必须覆盖消费者及高风险反例。缺环境标 blocked/not-run 并说明影响；不能静默跳过必须场景或缩小已有断言。

## 阶段判断

B 自检完成需要实现与必要自动检查通过；A 审核通过需要实际检查代码/版本/关键边界；M1 退出需要全部 P0、适用 NFR、真实账户/行情/模型和必要实机验证满足。模拟全过只能说明模拟范围通过。

## 当前阶段入口（M0 v1.0）

`python scripts/verify_stage.py --stage M0 --plan-version 1.0` 读取 [用例映射](../delivery/m0-stage-cases.json)，核验分支及通向固定父提交的完整线性历史，执行文档、diff、fmt、clippy、workspace tests、两套 Python 测试与 build。每个行为模式必须匹配真实通过的测试；零测试、缺模式、失败门禁都返回非零。继承 R1 的 Cargo 测试过滤和集成套件检查单独记录，父提交校验统一为原文档框架，旧报告检查由当前基线参数替代，旧人工缺口不删除。

`python scripts/package_stage.py --stage M0 --plan-version 1.0` 要求当前源码已有成功验证报告，必须由 Cargo 检查 release 构建，拒绝中途源码变化。按源码与 exe 哈希创建独立目录，不覆盖历史包。源码指纹覆盖 Cargo/实现/worker Python/脚本/测试及当前用例映射；叙述性文档不入该指纹以避免证据自引用，文档修改后须单独重跑文档门禁。完整 Git SHA 在最终交接取值，报告写 pre-amend 基点与阶段父提交。

机器结果在忽略的 `.local/reports/m0/verification.json` 和 `package.json`。人工/live 不由命令自动改为 passed；R1 命令保留历史作用域，不能用其旧包验收当前 M0。
