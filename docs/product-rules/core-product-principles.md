# DELTA 产品不变量

适用于所有阶段；具体功能在其承诺阶段验收，见 [需求](../requirements/product-requirements.md)。

1. **本地可用和数据拥有权**：账本、图表、笔记不依赖 LLM 在线。导出和可校验恢复是基本功能；凭据与数据发送范围明确。
2. **可信金融事实**：金额使用规定十进制口径，缺价格/汇率/成本显式缺失；不将入金当收益，不将模拟资产混入真实资产。
3. **结果能追溯**：统计、图表和 AI 结论引用同一数据修订。更正保留历史来源，旧报告提示过期。
4. **AI 通过共同能力完成工作**：业务数据和权限由宿主管理，模型负责理解、调用和解释；不能建立第二份数值或权限真相。
5. **开源优先与薄整合**：优先复用已验证上游能力，自研集中在差异化的业务整合、上下文与接口。新增自研通用基础设施需要说明现成方案缺口。
6. **先基本闭环、后循环增强**：首版完成资产复盘，随后补齐训练与策略基本流程，再按实际反馈优化；不以复杂布局、插件市场、通用 Agent 框架拖延可用闭环。
7. **能力声明诚实**：未实现入口不冒充可用；部分估值、模拟模型、离线数据、未验证平台都明确标识。SDK 覆盖不等于市场支持，开源不等于免费行情。

验收以需求/AC 和运行证据为准；违反这些不变量的实现不能通过改文案或降低测试掩盖。
