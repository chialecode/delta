## 6. 实施细化

### W00—W01：最小工程与证据基础

- 按[仓库地图](../dev-rules/repo-map.md)职责建立实际需要的模块；Rust core 不依赖 GPUI/DB/模型传输。ModelClient 负责通信；Rust 应用层负责工具与会话，Python 负责指标/日历等独立能力。
- 锁定 Rust/Python 与实际依赖，记录 Codex 参考提交和采用范围，保存来源、许可、启用特性、MSRV、native 依赖和可替换边界；普通工作不全量升级。
- 建立合成美股和 BTC/USDT 数据、两个账户、费用/分红/转账/更正/未知成本样本、OHLCV/FX/日历和恶意笔记；固定 seed、ID、时间，manifest 保存 hash。真实样本不入 Git。
- 期望值由手算或独立上游基准给出，至少精确包含 AC-02 的现金 1438、成本 600.6、已实现 38.6、未实现 29.4、总损益 68；不拿被测引擎输出回填期望。
- 建立假模型端点，能控制碎片 SSE、工具参数、无效引用、401/429/断流、超时/取消/压缩请求；走真实 Rust ModelClient 的两种适配，不能 stub 掉整个客户端后宣称协议通过。
- 使用公共 DTO/schema、版本/范围、错误、ID/取消，默认不引入公共网络 server。协议测试只在回环/stdio 与隔离目录。

### W02—W03：完整金融闭环

- 实现资料库设置、平台资料目录、账户种类、组合成员唯一性、记账本位币固定与报表币种切换。
- CSV 模板、显式字段/编码/日期/小数映射、预览错误/重复、接受行确认；预览失效/重复提交/事务失败和重导都可解释。原始行、批次与事件可追溯。
- 事件覆盖期初、买/卖、入/出金、转账、费用、利息、分红、拆股、冲销/替代；不可静默改历史。卖超持仓拒绝；未知成本不当零。
- FIFO 部分出售/费用分摊、第三资产支付费用、USD/USDT/USDC 独立、跨账户资产成本搬移、组合内转账与单账户外部流区分。
- 总资产/负债/净资产、手工估值日期、净投入/区间损益/费用、基础可比回撤；不完整给 partial/unavailable。TWR/XIRR 留后期，不能把余额增长当收益。
- 对账呈现账本/来源/差异/时点，不自动凑平。更正时版本/投影/报告过期同步，原报告证据可访问。

### W04—W06：行情、桌面与日志

- MarketDataProvider 的文件实现是本轮必需，至少 OHLCV/FX/公司行动/日历可版本化；带市场/场所/交易对、来源、复权、时区和覆盖，区分休市与缺数据。
- 没有在线账号时完成能力表与文件数据路径，不写“支持 Longport/某交易所实时行情”；Q-01 决定后在同接口加一条美股/加密实际路径。
- 指标为 MA/EMA/MACD/RSI，参数、初始化/预热、缺值和截断语义明确，TA-Lib 固定向量对照。向截止后行情注入极端值，当前窗口/指标不改变。
- 可用页面包含数据中心/导入、账户/资产、市场图表、日志、设置/任务和 AI 面板。缩放/平移/十字光标/定位、标记点击与笔记反向跳转实际可操作。
- Markdown 自动保存、标签、模板、中文搜索、多成交/计划关联、可选附件和 ChartContext 持久化；保存失败保留缓冲、崩溃后最近持久版本恢复。拆分计划的关联数量不超额。
- 未实现训练/策略不放可点击空页面；内部技术名不进入用户流程。界面状态遵守设计规则。

### W07—W08：Rust 模型客户端与统一 AI 能力

- 先读 [模型客户端合同](../design/rust-model-client.md)及固定 Codex 源码映射；围绕 ModelClient、协议适配、HTTP transport 与应用 AgentRuntime 分层。复用 reqwest/Tokio/serde/SSE parser，不引入完整 Codex 平台或额外 Agent 语言工程。
- Responses 与 Chat Completions 都实现文本流、工具调用/结果关联、用量与错误/终态；分别接入受控服务跑碎片 UTF-8、工具参数、截断、重复 ID、401/429/5xx、背压、超时、取消。已出现可见流事件后不得自动重放；用量缺失不当零。
- 只注册 get_data_quality/get_portfolio_summary/explain_pnl/query_trades/search_journal/get_chart_window；与 UI 使用同服务/快照。工具参数完整和模型工具回合正常结束后，Rust 独立校验 schema、scope、代次、预算及引用，再顺序执行。
- Rust/SQLite 保存原始转录、调用/回执、run、summary checkpoint，完整工具组不拆散。压缩用同一客户端完成受限摘要，原历史保留，范围由宿主重建；验证事务失败/取消不切换检查点、重启保留已提交回执。
- 连接设置显式 protocol/model/base URL/窗口/能力/credential_ref；官方连接推荐 Responses，兼容端点按实际协议。真实服务只验证授权配置；不硬编码模型，不静默回退。
- 客户端不加载 Codex/其他开发工具的 AGENTS/skills/插件/全局 auth，隔离探针验证无隐式配置/凭据读取、无 shell/文件工具。Python 指标进程不继承模型凭据。
- 报告把确定性值与模型文字分开，关键值绑定 result_id/evidence_id 并由宿主渲染。伪造引用/数值矛盾最多一次受限修正或失败，保留统计结果。
- retry、compaction、token/费用估计、取消和中断可见；切账户新运行/干净上下文，迟到消息不得写入新代次。缺模型时本地报告和其他业务可用，不伪造 AI 成功。

### W09：数据拥有权

数据库/附件/配置/Rust 会话备份有一致性清单；恢复到新目录，校验后切换，失败不覆盖旧库。迁移前备份和版本不匹配拒绝路径必测。

- 导出 CSV/JSON/Markdown 及关联清单；用户可以独立理解来源/币种/计算口径。
- 资料库删除展示路径与对象范围，关闭任务/句柄后执行，备份与外部模型副本边界提示清楚；测试只删除新建的隔离库。
- keyring 真值不落日志/命令行/备份；模型连接不读取环境中的其他应用凭据。日志脱敏、文件路径逃逸、附件缺失/损坏测试齐全。

### W10—W11：收敛与交付

- 同一套合成账户贯通全流程，美股和加密都运行，重启/备份恢复后数值/引用一致。
- 按 [用例清单](r1-cases.json)逐项给结果，性能记录数据量/硬件/测量法；假端点结果和真实端点结果分开。
- 打包 GPUI/Rust 模型模块与可选 Python/native 依赖；离线/无开发环境安装和许可 inventory 有证据。未完成的实机场景给真实可运行包和操作步骤，不用测试机成功代表干净安装。
- 连续修复自己可处理的实现/检查失败，完成自审后再交 A；不能把程序错误转入人工 ACT。
- 写 `docs/evidence/r1-delivery.md`（由 B 创建并登记），含全部包/用例/需求结果、源码基点/指纹、启动/构建命令、样本/产物、未测边界与集中事项 ID，更新 status/traceability/ADR 和必要正本。

## 7. 命令与证据格式

| 入口 | 要求 |
| --- | --- |
| `cargo fmt --all -- --check` | 工程格式 |
| `cargo clippy --workspace --all-targets -- -D warnings` | 静态检查，不能随意禁 lint |
| `cargo test --workspace --locked` | 领域/存储/契约回归；未运行桌面/真实服务不混入 passed |

| `python scripts/run_r1.py --demo` | 准备隔离合成库并启动桌面，保留调试/错误入口 |
| `python scripts/package_r1.py` | 生成 Windows 分发包与版本/许可清单，产物在忽略目录 |

工具入口可因实际工程采用同等替代，但 B 必须同步本表、README 与交付 prompt 并说明理由；不能给用户尚不存在的命令。Rust/Python 的实际依赖与脚本入口在创建后写入，锁文件安装不能依赖全局开发工具或额外 Agent 运行时。

自动结果输出 `.local/reports/r1/results.json`，格式至少含 plan_version、git_base、source_fingerprint、environment、cases[]（id/mode/status/command/exit_code/expected/actual/evidence/reason）。自动验证默认退出码只判自动组；missing/failed/blocked/not-run 任一必需自动用例使其非零。人工和 live 保持独立状态。完整阶段检查若含未执行的人工/真实用例必须失败，不得把自动组通过改称 S1 通过。

`r1-cases.json` 是本轮用例定义，产品期望值仍以 FR/AC/金融合同为准。只改调用步骤/增加子场景不应降低原验收。
