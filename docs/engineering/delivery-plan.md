# DELTA 实施路线与验收计划

版本 1.5 · 2026-11-12 · 按 [D-20 ～ D-23](../decisions/confirmed-decisions.md) 从文档治理基线重建项目，并按 D-31 在 M2 之后插入安装与更新阶段，整体演进为 **“M1 金融数据来源与本地自动化数据底座优先 → M2 完整资产复盘应用 → M3 Windows 安装包与更新 → M4 K 线训练 → M5 策略研究 → M6 扩展”**。当前执行状态见 [当前状态](../delivery/status.md)，当前唯一实施计划见 [M4 阶段计划](../delivery/stage-plan.md)（M3 已于 2026-11-12 集成并发布 v0.1.1，证据见 [M3 阶段报告](../evidence/2026-11-12-m3-stage-report.md)；M1 已于 2026-11-08 集成，证据见 [M1 阶段报告](../evidence/2026-11-08-m1-stage-report.md)；M2 已于 2026-11-09 集成，证据见 [M2 阶段报告](../evidence/2026-11-09-m2-stage-report.md)）。

## 1. 交付方式与阶段重排原则

1. **先解决金融数据来源，再构建上层应用**：没有可靠的美股/ETF、加密现货、汇率、拆股分红公司行动、交易日历与券商/交易所流水接入，任何桌面 UI 与 AI 分析都只是空壳演示。
2. **A 完整阶段计划 → B 连续实现/自检 → A 集中审核 → 用户授权具体远端动作 → push / PR / 经授权合并**：技术验证通过后在同一阶段内连续完成闭环；同一阶段 push 前尽量保持一个 commit（直接 amend）。
3. **工程完成、技术审核与产品验收分离**：Agent 侧阶段完成指可执行范围、必需自动证据通过且 A 审查收敛；真实个人账户或需私有 API Key 的在线验收在 [USER-ACTIONS](../../USER-ACTIONS.md) 独立推进，不阻塞免 Key 公共源与录制样本的工程收敛。

## 3. M2：完整资产复盘桌面工作台与 AI 证据问答（已完成）

M1 的实际验收限定为当前阶段计划与 [阶段报告](../evidence/2026-11-08-m1-stage-report.md) 的子集：整库 inception 报告、日频近似收益率、声明的账单模板和公共行情服务。schema 3 / `m1-ledger-3` 不表示完整 M2 组合配置、区间 UI、AI、训练或策略已完成；追踪表对整项需求保留 planned/in-progress。

在 M1 数据底座稳固后，按 [D-21](../decisions/confirmed-decisions.md) 与 [ADR-0003](../decisions/0003-first-round-stack.md) 采用长桥最新 **GPUI Kit（`0.8.x` / `0.9.x`）官方 `DockArea` + `DockSkin` + `Panel` + `DataTable` + `Card` 面板体系**构建桌面工作台（K 线面板配视口滑动窗口切片）与自研 Rust `ModelClient`（Responses / Chat Completions 双协议）：

1. 图形化数据中心：一键触发 M1 增量同步，可视化查看数据源状态、覆盖缺口、复权/公司行动与对账差异。
2. 资产与账本视图：多账户/组合净资产、FIFO 批次、资金流与区间损益解释。
3. 专业 K 线图表与交易笔记：10 万根 K 线窗口加载、MA/EMA/MACD/RSI 副图、成交与笔记双向锚定跳转、Markdown 自动保存与附件管理。
4. 只读 AI 复盘：基于同一 `dataset_version` 与账本修订号回答个人数据问题，输出可点击打开的证据引用。
5. 开放导出、删除预览、Windows 打包与干净机器验收：按用户安装（无需管理员），正式版 `%LOCALAPPDATA%\Programs\delta`、开发版 `delta-dev` 可同时安装，卸载保留数据（D-26，见 [安装与数据位置](../dev-rules/data-and-security.md#install-and-data-locations)）。

## 4. M3：Windows 安装包、版本与自动更新（已完成）

M2 只交付了静态 CRT 便携 ZIP 与包内 `package-install`，没有标准安装程序、开始菜单与“应用和功能”入口、图标与版本资源、单实例与更新路径。M3 在不改变数据位置（D-26）的前提下补齐：

1. 版本与身份：正式版 `0.1.N` 来自 `v0.1.N` 标签，开发版 `<下一版本>-dev.<UTC 时间戳>`；可执行文件带图标与 VERSIONINFO；每个通道独立的单实例互斥量与本地控制管道（聚焦、为更新而保存退出）。
2. 安装程序：Inno Setup 7.1.x 按用户安装（无需管理员），正式版 `delta` 与开发版 `delta-dev` 各有独立 AppId、安装目录、开始菜单项与卸载入口，可并存；升级与卸载不删除应用数据，不强杀运行中的应用；接管 M2 便携安装。
3. 开发版本地更新：`delta-cli install-dev` 构建并静默安装 `delta-dev`，运行中则先请求保存退出再重启。
4. 正式版在线更新：GitHub Releases 发布 `setup.exe`、`latest.json` 与 Ed25519 签名；客户端只接受 HTTPS、白名单主机、内置公钥验签且更高版本，安装前一致性备份；首个公开发布需用户单独授权。
5. 门禁：测试身份 `delta-test` / `delta-dev-test` 与回环更新源完成静默安装、升级、迁移、更新与卸载演练，不触碰开发者本机的两个通道。

## 5. M4：K 线训练（当前阶段）

统一回放时钟（`visible_until`）→ 市价/限价/止损/OCO 订单与费用模型 → 逐步推进与资金预留 → 训练持久化与恢复 → 执行质量报告（含 MAE/MFE）→ 结束后 AI 复盘。

M4 只覆盖日线、单标的、现货做多与整笔成交；撮合引擎（`delta-core::sim`）按多标的固定排序设计，供 M5 回测复用。部分成交、止损限价、做空/衍生品、多标的训练和分钟级回放登记在 `LOOP-06`。工作包、定案与用例见 [M4 阶段计划](../delivery/stage-plan.md)，B 实现与自检结论及未测边界见 [M4 阶段报告](../delivery/stage-report.md)。

## 6. M5：策略研究

有类型的条件表示 → 日线批量扫描（M1 SQLite 行情经 `dataset_partition` 抽象，按 `OSS-10` 视需要接入 Parquet/DuckDB） → 纯 Rust 受控策略执行引擎（带超时/步数配额与取消隔离） → 与 M4 共享撮合引擎的统一回测 → 实验版本与样本外/滚动评估 → 历史成分股幸存者偏差标注。

## 7. M6：按价值排序扩展

小时/分钟周期、实时流推送、更多券商/交易所连接器、多图联动、节点式策略图、衍生品与跨平台发布。
