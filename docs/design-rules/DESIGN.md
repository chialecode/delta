# DELTA UI 与交互约束

适用于窗口、组件、图表、状态和文案变更。工作流见 [交互设计](../design/interaction-and-workflows.md)，金融口径见 [金融规则](../design/financial-engine.md)。

## 首版设计基线

GPUI Kit 原生组件优先，语义主题/间距/字体与公共组件集中定义，避免各页硬编码一套。沿用上游成熟交互，再实现 DELTA 的范围、证据与金融状态。本次采用用户提供图片的白灰橙方向，具体布局和 token 见 [工作台视觉规格](../design/workbench-visual-spec.md)；最终观感由 H-01 记录。

信息顺序为范围与数据质量 → 主要结果 → 分项解释 → 原始证据。金额使用等宽数字/右对齐、明确币种和符号；缺失值不可显示成 0。涨跌采用符号与文字配合颜色，并支持两种市场配色习惯。

主导航只开放已可用功能；明确的视觉样例可保留禁用模块和局部样例标记，不能提供伪成功操作。布局先满足稳定默认使用，不先建设任意 Dock 编排。AI 面板显示当前模型、数据范围、运行/取消状态和可打开证据；协议适配器、RPC 等实现名称不进入普通用户操作流。

## 必须覆盖的状态

空库、加载、局部缺失、离线、鉴权失败、保存失败、取消、过期报告、恢复失败都给明确原因与下一操作。流式 AI 文本在校验前标生成中；保存失败不能显示已保存。

键盘可操作导航、导入、表格、笔记、图表控制与对话框；保留焦点，Esc 行为一致。中文输入法组合态不能误提交；125%/150% 缩放、小窗口和长数字不遮挡关键操作。

## 证据要求

功能 UI 变更提交最终运行界面证据、环境/主题/缩放与关键步骤；自动布局测试不能代替真实输入法。低影响文案和样式不强写镜像实现的单元测试；金额含义、状态误导和主要操作路径仍需核对。

达到 NFR 性能必须实测硬件、数据量、窗口和统计口径。上游支持某平台不等于 DELTA 已验收该平台。
