# DELTA UI 与交互约束

适用于 M2+ 桌面阶段窗口、组件、图表、状态和文案变更（M1 阶段仅交付 CLI 与自动化数据底座，不构建桌面 GUI）。工作流见 [交互设计](../design/interaction-and-workflows.md)，金融口径见 [金融规则](../design/financial-engine.md)。

## 桌面与图表设计基线

1. **核心与 UI 分阶段衔接（D-21）**：按 [ADR-0003](../decisions/0003-first-round-stack.md)，桌面层不拥有独立金融公式、SQL 或指标口径。M2 桌面框架采用长桥最新 **`gpui-kit`（`0.8.x` / `0.9.x`）官方 `DockArea` + `DockLayout` + `DockSkin` + `Panel` + `DataTable` + `Card` 面板体系**（摒弃旧 `0.6.6` 手写绝对布局；`gpui-kit 0.9.0` 无官方 `Card` 组件，卡片按官方 story 模式自建 `MetricCard`，见 M2 计划 S-15（计划已归档于 Git 历史，结果见 [M2 阶段报告](../evidence/2026-11-09-m2-stage-report.md)）），并在主 K 线与回放 `Panel` 外层封装 GPUI 视口滑动窗口（`visible_range` 滚轮缩放与拖拽平移切片），实现 10 万根历史 K 线的按窗切片渲染、副图联动与交易/笔记标记。
2. **信息层次**：范围与数据质量（含数据源、同步时点、复权口径、缺失告警）→ 主要结果 → 分项解释 → 原始证据。金额使用等宽数字/右对齐、明确币种和符号；缺失值不可显示成 0。涨跌采用符号与文字配合颜色，并支持两种市场配色习惯。
3. **诚实能力边界**：主导航只开放已可用功能。AI 面板显示当前模型、数据范围、运行/取消状态和可打开证据；内部协议名称不进入普通用户操作流。
4. **视觉风格（2026-11-09 用户要求，参照长桥桌面客户端的信息密度与布局，不复制其品牌资产）**：浅色白底、发丝分隔线、13 px 基准字号、深色主按钮与青绿强调色；外壳为顶部工具栏（标识、当前页、账户、紧凑范围输入、AI/任务开关）＋左侧图标导航栏（图标在上、短标签在下，设置置底）＋底部状态栏（范围、版本、截止日与币种）。Dock 面板自绘标题，不显示内部类型名；市场页为“自选列表 | 报价头（收盘、涨跌、开高低量）＋图表工具条＋K 线”，涨跌额与涨跌幅由 `delta-app` 以 Decimal 计算；总览为净资产主值＋卡片网格；表格表头浅灰、数字右对齐。主题集中在 `delta-desktop::theme`，图标须通过 `gpui_kit::assets::Assets` 注册。

## 必须覆盖的状态

空库、数据同步中、局部缺失（`partial`）、离线、鉴权/限流失败、保存失败、取消、过期报告、恢复失败都给明确原因与下一操作。流式 AI 文本在校验前标生成中；保存失败不能显示已保存。

键盘可操作导航、导入、表格、笔记、图表控制与对话框；保留焦点，Esc 行为一致。中文输入法组合态不能误提交；125%/150% 缩放、小窗口和长数字不遮挡关键操作。

## 证据要求

M2+ 功能 UI 变更提交最终运行界面证据、环境/主题/缩放与关键步骤（隐藏窗口截图：`DELTA_UI_CAPTURE_DIR=<忽略目录> cargo test -p delta-desktop --lib capture_workbench_pages -- --ignored`，不激活、不置前，输出六页 PNG）；自动测试与真实输入法/缩放人工检查分别记录。达到 NFR 性能必须实测硬件、数据量、窗口和统计口径。
