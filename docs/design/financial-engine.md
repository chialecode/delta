# DELTA 金融计算与模拟规则

版本 0.1 · 2026-09-25 · 所有 UI、报告、训练与回测共用的口径

## 1. 数值、范围和时间

账本金额、数量、费用和舍入使用 Decimal。指标统计可使用 f64，但需要定义空值、预热和比较容差；浮点结果不能未经验证直接入账。

每个结果绑定：账户集合、起止时间、报表币种、成本法、估值源、费用规则和计算版本。时间区间为 `[start, end)`；期初估值和资金流边界的先后顺序明确保存。

数量按 lot_size、价格按 tick_size、费用按收费币种精度舍入；舍入模式与收费层级（每成交/每订单/每日）来自预设。中间值尽量保留精度，在规定结算边界舍入。

## 2. 记账与成本

默认现货、仅做多、FIFO。买入直接归属该成交的费用计入分析成本；卖出费用扣减卖出净收入。汇总费用作为解释项展示，不能从已经包含费用的损益中再次扣除。本分析口径不等同于任意司法辖区的税务口径。

同币种示例：初始 USD 2000，买入 10 股×100，买入费 1；再卖出 4 股×110，卖出费 1。

```text
买入总成本 = 1000 + 1 = 1001
单位成本 = 100.1
卖出净收入 = 440 - 1 = 439
已实现损益 = 439 - 4 × 100.1 = 38.6
剩余数量 = 6
剩余成本 = 600.6
期末现金 = 2000 - 1001 + 439 = 1438
若期末价格为 105：持仓市值 = 630，未实现损益 = 29.4
总净资产 = 2068，总损益 = 68 = 38.6 + 29.4
```

对应买入分录：借持仓成本 1001、贷现金 1001。卖出：借现金 439、贷持仓成本 400.4、贷已实现收益 38.6。上述已将费用计入成本和净收入，不再额外记录同额费用支出分录。

多次买入按 FIFO 分配。部分费用分摊保留高精度，最后一次分配吸收剩余舍入差，保证全部卖出后的累计成本与原始总成本一致。

费用以第三资产收取时，同时减少该资产数量，并按事件时点可靠价格折算为费用价值；此资产自身的成本处置与汇兑影响也需要记录。缺价格时事件/损益进入待补全，不能只减现金或忽略费用。

资料库固定记账本位币，保留所有原币数量。外币现金使用携带成本和处置规则确认汇兑结果，市场估值形成未实现汇兑变化；报表币种切换只是分析视图转换。

期初持仓可标记成本已知或未知。未知成本可纳入当前估值，但相关已实现/未实现收益不计算为零。超出持仓的卖出在现货模式拒绝，缺失历史时要求补录期初或修正数据。

## 3. 转账与公司行动

内部转账本金在两端数量匹配，手续费单独处理。例如从 A 转出 1000、B 收到 998：若是本金 998 加手续费 2，必须明确区分，不能凭差额推断全部为费用。

在包含 A/B 的组合内，本金为内部流转，手续费降低净资产；只看 A 或 B 时，本金是该统计范围的外部现金流。转账在途可使用清算账户暂存，避免按不同到账日期重复计入或暂时丢失。

跨账户转移同一证券/加密资产时搬移数量及历史成本批次，不虚构卖出收益。转账两端币种不同时需识别换汇/兑换事件，不能按同币种本金直接配对。

2:1 拆股使数量翻倍、每单位成本减半、总成本不变。现金分红按照适用记录/支付规则登记应收或现金收入。M1 可以先按支付日现金记账，但必须在报告说明；将来增加应收时避免重复收入。

估值、模拟执行优先使用原始价格并显式处理公司行动；技术指标可使用明示的复权序列。使用总回报序列作为基准时不再叠加一次分红。拆股/分红数据缺失时标注不可比较区间。

## 4. 估值与区间损益

```text
资产市值 = 数量 × 估值价格 × 转换到报表币种的汇率
净资产 = 资产合计 - 负债合计
区间损益 = 期末净资产 - 期初净资产 - 净外部资金流
净外部资金流 = 外部投入 - 外部取出
```

资金流按发生时点汇率折算；不是用期末汇率统一回填。负债和其他资产也遵循一致的估值时点。

估值不能读取目标时刻之后的价格。休市时可用最近有效价格，但显示时点和过期状态；市场开市而行情丢失时采用来源特定的过期阈值。不同资产阈值不同，不统一假设“24 小时内都新鲜”。

缺少价格、汇率或必要期初值时输出 partial/unavailable 及缺项，不把未知项当零。手工估值带 as_of；默认不把一条后来录入的估值当成历史所有日期的估值。

M1 优先展示原币损益和折算后的总损益。若分解价格与汇率影响，固定分解次序：对期间数量不变的一笔外币敞口，采用

```text
价格影响 = q × (P1 - P0) × FX0
汇率影响 = q × P1 × (FX1 - FX0)
两者之和 = q × P1 × FX1 - q × P0 × FX0
```

有中途交易时分段计算，费用/分红/资金流单独归因。不能用该静态公式解释任意交易组合；无法完整归因的差额列明，禁止强行归零。

## 5. 收益率与风险指标

### 5.1 时间加权收益率 TWR

在每个外部资金流时点切分子区间。`V_i_start_after_flow` 为流入/流出后的期初估值，`V_i_end_before_next_flow` 为下次资金流前估值：

```text
r_i = V_i_end_before_next_flow / V_i_start_after_flow - 1
TWR = product(1 + r_i) - 1
```

需要资金流时点估值，或明确的日频近似规则。只有日末值时可采用标注假设的近似/Modified Dietz；不得标为精确 TWR。期初资产为零、负净值或估值缺口时定义分段重启/不可用状态。

### 5.2 资金加权收益率 MWR / XIRR

以投资者视角记录流量：期初组合价值和后续投入为负，取出与期末剩余资产价值为正；同日流量合并。对给定天数基准求解：

```text
sum(CF_i / (1 + r)^((date_i - date_0) / 365)) = 0, r > -1
```

求根使用范围扫描＋稳定数值算法，报告收敛区间。没有正负流量、没有解、多根或初值敏感时返回对应状态；不能拿某次求根的一个值冒充唯一答案。

### 5.3 回撤与交易统计

投资最大回撤来自可比净值序列 `N_t`：`max(1 - N_t / max(N_0..N_t))`。外部资金流需先剔除；资产金额下降另称“资产变化”，避免把出金当作投资亏损。

胜率以明确的已关闭交易组为分母，盈亏为零单独统计；不能直接用每条成交作为一笔独立交易。Profit Factor 为总盈利/亏损绝对额，零亏损输出特殊状态。平均盈亏比、期望值显示样本数。

MAE/MFE 按持仓期间可获得的价格序列计算；仅日线数据时为日线精度的估计，多次加仓/减仓时说明以逐时持仓损益还是入场单位价格衡量。

Sharpe、Sortino、年化波动列为后续分析；实现时明确收益频率、无风险利率、年化系数和缺失处理。美股交易日和加密全年交易不共享未经说明的 252 日假设。

## 6. 历史可见性与指标

所有模拟数据访问带 `visible_until`，只能返回在该时刻已完成且可获得的数据。日线收盘信号默认下一交易时段开盘才可成交。高周期 K 线未闭合时，不作为已完成指标输入。

指标预热区间可以早于训练展示起点，但结束时点必须不晚于回放时钟。不同指标初始化、EMA 种子、RSI 平滑和 MACD 预热可能不同，需要锁定参考实现与参数。

历史下载的数据可能有修订或利用后来公司行动形成的复权。保存数据版本、复权时点和可得性等级；缺少历史发布时间的数据标明局限。对未来数据做哨兵值注入，是检测图表/指标/策略读取越界的必要测试。

UI 隐藏未来并不等于底层安全；工作进程只能接收截断数据或受限查询。随机抽样预先固定 seed 和范围，不能因结果不理想而在后台重新抽取。

## 7. 模拟订单与成交

状态：created → accepted → active → partially_filled / filled / cancelled / expired / rejected。订单在提交后的规定事件边界生效，保存 submitted_at、eligible_at、激活顺序和拒绝原因。

首批假设：现货、做多、禁止负现金/负持仓、无融资。M2 基础模型可全额成交，明确“不模拟流动性限制”；支持参与率/部分成交属于后续模型版本，不隐藏假设。

| 类型 | 日线基础规则 |
| --- | --- |
| 市价单 | 下一可交易 K 线开盘为基准价，再应用方向性点差/滑点 |
| 买入限价 | 后续开盘低于限价可在开盘附近改善成交，或最低价触及限价时按规定成交；最终价不得高于限价 |
| 卖出限价 | 与买入对称；最终价不得低于限价 |
| 卖出止损市价 | 开盘跳空低于触发价时按开盘基准及不利滑点，不能保证止损价；盘中触及按模型处理 |
| OCO 止盈/止损 | 一个成交后另一个取消；同根触及两者按声明的顺序假设 |

限价单的最终费用不改变成交价约束，但要检查总资金充足。止损限价单与止损市价不同，M2 可只开放止损市价；不能把两者混为一类。

只有 OHLC 时无法恢复真实盘中路径。M2 默认对多头场景使用固定路径 `Open → Low → High → Close`，先处理开盘跳空，再按每段经过价格的顺序触发订单。对开盘仍在止盈/止损区间内的已有多头持仓，这会使同根双触达先执行止损；对其他订单组合不宣称一定是最坏结果。

同一标的同一根 K 线的全部订单共用该路径，新入场的附属止盈/止损仅在入场之后激活，不能利用路径中已经过去的高低点成交。报告标注路径假设及歧义成交数量。更细数据或其他路径政策属于新的撮合版本，禁止为每笔单独挑选互相矛盾的有利路径。

多标的同时下单共享资金时使用固定排序（事件时间、策略优先级、标的 ID、订单序号）；先预留资金再尝试成交。未来可增加按目标仓位比例分配，算法变更必须版本化。

缺失 K 线不能补出虚构成交；休市进入下一交易时段。成交量为零、停牌或来源标记不可交易时禁止成交。

## 8. 费用与交易环境

费用预设至少包括市场/场所、有效期间、按成交额费率、按股/单位费用、固定费用、最低/最高收费、收费币种、舍入和计费层级。规则是可组合组件，避免一个巨大公式覆盖所有平台。

例如最低收费按订单计时，拆成多个部分成交后应累计并在订单结束时结算，不能每个 fill 都扣一次最低费用。

点差/滑点与手续费分开：固定 tick 或 bps 为初始模型，且记录双边/单边定义。以 OHLC 模拟无法可靠判断 maker/taker 时，使用明确假设或偏保守费率，不宣称还原真实撮合队列。

费用版本在训练/实验创建时冻结。当前交易所费率不能默默应用到十年前的回测；用户自定义预设允许这样做，但报告应显示这是场景假设。

## 9. 结果可复现与对照

确定性部分使用固定输入、版本、排序与随机种子，产生一致订单、成交、成本和 Decimal 损益。浮点指标按指定绝对/相对容差比较；不同硬件上不能默认宣称所有浮点字节完全一致。

训练与回测输入相同订单序列时，必须产生相同结果。回测基准使用相同区间、资金、估值和分红口径；若成本假设不同必须展示。

对照验证包含手算的小样本、开源参考指标以及现金/数量/成本守恒性质测试。修复计算错误产生新引擎版本，原报告保留并标识旧版本，不悄悄覆盖结果。
