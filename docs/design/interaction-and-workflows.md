# DELTA 交互与工作流设计

版本 0.3 · 2026-11-12；M2 与 M4 实际交互边界见相应章节，策略研究（M5）仍为后续设计。

## 1. 信息架构

主导航使用用户任务命名：**总览、市场、资产、日志、训练、策略**。底部提供数据中心、设置和后台任务。未交付的模块不显示可点击的空壳入口。

顶栏显示全局搜索、当前组合、报表币种和数据状态。账户范围与日期仅在支持联动的页面共享，切换范围必须在页面上可见，不能悄悄改变已保存实验。

M2 提供总览、市场、资产、日志、数据中心、设置六页；M4 起激活第七页**训练**（`策略`页在 M5 交付前仍不开放空壳入口）。控件将操作交给 `WorkbenchController` 的串行后台队列，前台只维护输入和展示。范围切换先在旧范围保存脏笔记；保存失败时保留旧范围与缓冲，成功后清除旧金融结果、图表下钻和 AI 展示，再加载新范围。后台完成通知保留保存期间的新输入及尚未提交的设置。

默认桌面布局为左侧导航、中部工作区、可展开的右侧详情/AI 面板、底部任务状态。复用 GPUI Dock 布局；先提供稳定默认布局，再开放自定义分屏和布局保存。

## 2. 页面职责

| 页面 | 首要信息 | 主要操作 | 关联跳转 |
| --- | --- | --- | --- |
| 总览 | 净资产、净投入、损益、数据覆盖和待对账事项 | 切换范围，查看变化原因 | 账户、损益明细、复盘 |
| 市场 | 自选列表、K 线、指标、交易和笔记标记 | 搜索标的、选日期、写笔记 | 成交详情、训练 |
| 资产 | 账户、持仓、流水、成本与余额差异 | 导入、记账、转账配对、核对 | 图表、笔记、原始行 |
| 日志 | 时间线、标签、交易计划和正文 | 新建、关联、搜索、复盘 | 图表上下文、成交组 |
| 训练 | 已见历史、模拟订单、计划与回放控制 | 逐步推进、提交订单、暂停 | 结束报告、训练笔记 |
| 策略 | 条件、代码、实验、结果比较 | 扫描、回测、比较 | 命中图表、实验成交 |
| 数据中心 | 数据源、导入批次、覆盖区间和同步记录 | 映射、重试、补全、排错 | 对应账户/标的 |

总览优先展示少量可靠指标。TWR、XIRR 等在数据满足条件且功能已交付时显示；复杂指标不占据首次使用的主流程。

## 3. 首次使用与导入

1. 创建本地资料库，选择报表币种和界面时区；说明可后续修改报表设置。
2. 添加账户；选择手工维护或 CSV 导入。提供可直接使用的示例模板和离线演示数据。
3. 选文件并映射字段；识别分隔符、编码、日期和小数格式，存在歧义时要求用户选择解释方式。
4. 预览原始行、规范化事件、错误和疑似重复。标的/费用币种/时区缺失时不擅自猜值入账。
5. 显示预计新增、跳过和待处理的数量。用户可修复或明确排除错误行，排除项写入批次报告。
6. 确认后事务写入。部分有效数据可作为一个明确选择的批次提交；不能静默导入一部分并宣称全部成功。
7. 进入核对页，显示现金和持仓差异、缺失期初成本、行情和汇率缺口。
8. 核对后进入资产总览，并从一笔成交引导查看图表、添加理由。

同一文件再次导入提示“此账户已导入该批次”，允许查看记录或发起映射修订流程。跨文件疑似重复提供并排比较，不以金额相同作为自动删除理由。

M2 使用内置平台预设与严格字段校验，文件、账户或预设改变后必须重新预览；尚未提供任意字段拖拽映射编辑器。数据中心展示真实同步 phase、已准备/已发布记录和后台资源释放状态，取消接受与作业结束分别显示。

## 4. 资产变化分析

用户在总览点击某期间的损益，展开：期初净资产、净外部资金流、投资损益、期末净资产。下一层展示已实现、未实现、分红利息、费用和汇率影响；不能精确分解时保留“未归因项”及原因。

从统计进入成交流水时保留原组合、期间和币种，并显示筛选条件。流水详情展示来源批次、原始行、费用、成本批次和笔记。

余额核对以“账本计算值 / 来源快照 / 差额 / 快照时间”呈现。解决方式包括补录缺失事件、配对转账、修正映射和登记明确的调整事件。调整事件需要理由，可回看原始差异。

手工资产与负债的估值展示估值日期和方式。净资产中出现缺价项目时显示“已知部分估值”，并列出未纳入项，不能展示无提示的完整总资产。

## 5. 图表与日志关联

图表保存的上下文包括标的/交易场所/周期/时间窗口/复权模式/指标及参数。笔记可选择固定数据版本，或按最新数据打开；最新数据与记录时不同要提示。

图表内点击买卖标记打开成交详情；点击笔记标记打开日志。由笔记返回图表时恢复上下文，并把锚点置于视窗中央附近。

成交分组由交易计划或用户显式关联定义，不能仅按“同一标的同一天”自动视为同一决策。可自动建议分组，但保留修改能力。

日志编辑器采用 Markdown 和简洁模板。顶部结构字段默认折叠，正文优先；保存状态包括“正在保存 / 已保存 / 保存失败可重试”。新建关联笔记时自动带入成交、标的和时间，用户只需输入理由。

M2 停止输入 1 秒或失焦后保存新修订。保存失败保留错误原因与缓冲；保存期间继续输入时，旧回执只推进已持久化修订，不覆盖新正文。首次保存记录账户 owner 与“复盘日期”；历史分析按复盘日期过滤，训练截止还检查实际保存时刻。搜索达到候选/结果上限显示 Partial 提示。

图表滚轮缩放、鼠标拖动平移、日期跳转、键盘控制及十字光标使用同一个 `KlineViewport`。成交/笔记标记可由鼠标或列表按钮打开；Esc 清除光标。复权与指标切换在后台重新加载，固定版本与最新版本的差别保留提示。

## 6. 训练流程

创建训练时选择市场类别（全部 / 美股与 ETF / 加密现货）、候选范围或指定标的、历史区间、展示/训练/揭示根数（默认 `120 / 250 / 60`）、随机种子、初始资金（默认 `100,000` 报价币种）、费用预设版本（`fee_profile_version`）和隐藏开关。隐藏模式默认开启，关闭未来行情、真实日期和可直接查出历史结果的标的名称（显示为“标的 A（美股/ETF｜加密现货）”与“第 n 根”）；开始前允许显式“换一个”重抽并入库记录，开始后禁止更换片段；恢复已保存训练保持原设置。

训练工作区（`delta-desktop::training_ui`）包含训练运行列表（继续、重新尝试、查看报告、删除预览）与主训练区，复用 `KlineViewport` 与自绘 K 线图表（支持鼠标悬停十字光标、拖拽平移与滚轮缩放），顶部常驻显眼的**“模拟训练”**标识与独立模拟视觉强调色，订单、资金和收益始终来自模拟训练账户。下单面板实时计算并展示价格、数量、预计总成本与预估手续费（支持市价、限价、止损市价、OCO 及入场附带止盈/止损计划，`DAY` / `GTC`）。快捷键严格分离防误触：`N` 或 `→` 推进下一根 K 线（当焦点位于任何文本输入框时不触发推进，且**绝不**提交委托），提交委托必须显式点击确认或按 `Ctrl+Enter`；`P` 暂停运行，`O` 聚焦委托数量输入，`J` 聚焦训练笔记理由输入，`Escape` 退出当前输入框焦点并清除图表十字光标。

界面可以查看已揭示历史，但不能回退时钟后覆盖原订单。重新尝试生成带 `parent_run_id` 的独立新运行并保留原训练不变。暂停或关闭重开后从检查点与事件日志精确恢复订单状态、随机种子和回放进度。

点击“结束训练”后按固定三步复盘顺序展开：**先展示执行过程、训练报告（`m4-report-1`）与用户自主评分**（此时隐藏模式仍保持脱敏，防止看结果先入为主），用户显式点击**“揭示”**后才展示后续 60 根行情与真实标的/日期，并可在 `finished` 状态下开启右侧只读 AI 复盘（`ScopeTarget::TrainingRun`）。用户可以把训练笔记归档到真实日志（标注“来自模拟训练”），模拟委托与成交永不进入真实账本。桌面端只消费 `delta-app` 同步 DTO，与 `delta-cli training` 子命令共享同一套宿主服务。

## 7. 策略流程

创建扫描条件 → 选标的池和数据时点 → 校验指标预热与覆盖 → 扫描 → 查看命中原因 → 打开图表。

转为回测时补齐仓位、入场/退出、成交时点、费用、初始资金和基准。运行前摘要明确显示假设，例如“收盘产生信号，下一个交易时段开盘尝试成交”。

实验页按运行展示状态、参数、指标和数据版本。比较实验时检查市场范围、区间和币种是否一致；不同条件可以比较，但差异必须可见。

策略规则编辑器复用现有代码/表单编辑组件。参数面板、运行日志与错误定位优先于复杂 IDE 能力。节点图在统一策略表示稳定后加入。

## 8. AI 交互

右侧助手默认继承当前页面可见的范围；发送前可看到模型、账户、期间及是否包含笔记。用户可把范围固定，避免切换页面后误带入更多账户。

报告由摘要、计算结果、证据和局限组成。引用是可点击的业务对象，统计结论可展开样本。生成中的文本不伪装最终计算结果；失败时保留工具结果并允许重试。

关闭“包含笔记”、切换账户或连接后清除旧报告/证据展示并失效在途结果；打开已保存报告也重新检查当前范围。模型设置重启后恢复协议、端点、模型和预算，API key 永不回填；留空表示保留已有凭据。连通性检查只发送固定问题，不发送资料库内容。

M2 不提供 AI 修改账本按钮。后续笔记/标签建议使用变更预览，可逐条接受；策略建议要经过校验和回测才能保存为可运行版本。

## 9. 通用状态与可访问性

| 状态 | 页面行为 |
| --- | --- |
| 空资料库 | 提供导入/示例入口，说明需要的数据 |
| 缺行情/汇率/成本 | 显示具体缺口、受影响指标和补全入口 |
| 同步中/受限流 | 保留已提交数据；显示进度、上次成功时点和重试状态 |
| 结果过期 | 保留原报告；显示发生更正及重新计算入口 |
| 本地文件写入失败 | 保留编辑缓冲，提供重试或另存，不能显示已保存 |
| LLM 不可用 | 保留全部本地功能及既有报告 |
| 任务取消 | 显示取消结果与已完成阶段；未完整结果不能标为成功 |

配色支持红涨绿跌和绿涨红跌；涨跌同时使用符号/文本。键盘可以到达导航、表格、图表控制和对话框；明确焦点顺序与 Esc 行为。中文输入法、125%/150% 缩放、长数值和小窗口必须在桌面原型阶段验证。
